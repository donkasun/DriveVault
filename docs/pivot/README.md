## TL;DR

- **Pivot 1 — Enthusiast Garage:** Car profiles + build logs built for enthusiasts. CRLO refuses this segment. Growth engine.
- **Pivot 2 — Compliance Guardian:** SL-specific renewal reminders before penalty. CRLO can't do this. Monetization engine.
- **Model:** Free enthusiast garage drives acquisition. DriveVault Pro (Rs. 590/yr) unlocks full compliance reminders.
- **Biggest risk:** Willingness to pay against CRLO's free tier. Validate before building paywall.
